## Stage 2 — Design System + Public Website Foundation (✅ complete, same session)

User confirmed **Next.js** for the frontend. Scaffolded `web/` (Next.js 16, App Router,
Turbopack, React 19, TypeScript, Tailwind v4).

Used the `ui-ux-pro-max` skill for design-system generation (per spec §5's own suggestion to
use existing design tooling). The auto-matched result leaned into a "luxury real estate"
aesthetic (Cinzel serif, oversized display type, teal marketplace colors, "Exaggerated
Minimalism" style) that directly contradicted the spec's explicit anti-patterns (avoid fake
luxury imagery, avoid generic AI-SaaS look, association-focused not marketplace/editorial).
Overrode it by hand with targeted `--domain color`/`--domain typography` searches: a
"Government/Public Service" navy+blue palette and "Corporate Trust" typography (Lexend /
Source Sans 3). Persisted to `design-system/reak/MASTER.md` with the override rationale
documented inline, so a future session doesn't get confused by the two matches.

Built: design tokens (light + dark, `prefers-reduced-motion` handling) in
`web/src/app/globals.css`; base UI primitives (`Button`, `Badge`, `Card`, `Alert`,
`Input`/`Label`, `Skeleton`, `EmptyState`) in `web/src/components/ui/`; site header (with
accessible mobile nav disclosure) and footer; all 20 public routes from spec §4.1 under a
`(public)` route group (kept separate from the root layout so `/portal` and `/admin` won't
inherit this chrome later); the homepage with all 15 spec-ordered sections; `robots.ts` and
`sitemap.ts` for SEO.

Deliberately did **not** build: Tabs/Dialog/Dropdown (nothing on the public site needs them
yet — will add via Radix when Stage 5's member portal actually needs them, not speculatively);
working membership-application/contact/login/password-reset forms (no backend exists yet —
showing a non-functional form would violate "no fake login" / "no fake data flow", so these
routes show honest "not available yet" states instead); real mission/vision/benefits/legal
copy, member listings, news/notices/events (no CMS yet — `EmptyState`/`PagePlaceholder`
throughout, per §22's prohibition on fabricated content, including catching and fixing an
early mistake where the hero/metadata implied "REAK" stood for "Real Estate Association of
Nepal" — the spec never actually says what the acronym expands to).

**Verified**: `npm run build` (24 routes, 0 errors), `npm run lint` (clean after fixing one
unescaped-entity error), dev server smoke test via curl (all routes 200, unknown route → 404,
robots.txt/sitemap.xml 200), server log checked for runtime warnings (none), homepage HTML
spot-checked for expected empty-state copy.
